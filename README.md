# mostel28 — басейн

Самостійний односторінковий тизер нового треку. Сторінка працює без збирача й зовнішніх JS-залежностей.

## Перегляд

Відкрийте `index.html` у браузері. Обкладинка міститься в `assets/avatar.png`.

## Вміст

- `index.html` — структура й український текст
- `styles.css` — адаптивна композиція, палітра та анімації води
- `main.js` — повтор вступної анімації й хвиля при натисканні
- `assets/avatar.png` — надане зображення артиста
